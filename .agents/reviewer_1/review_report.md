## 2. Adversarial Stress-Testing & Edge Cases

The following edge cases and potential failure modes were actively stress-tested against the implementation plan:

### 1. Trailing Slash Edge Redirect & Query String Preservation
- **Stress-Test**: Does `workers/app.ts` trailing slash redirect preserve URL search params (e.g. `/location/bandra/?utm_source=google`)?
- **Finding**: Yes. `const url = new URL(request.url); url.pathname = url.pathname.slice(0, -1); return Response.redirect(url.toString(), 301);` reconstructs the full URL including `url.search`, preventing UTM and tracking parameter loss.

### 2. Canonical Tag vs 301 Redirect Consistency
- **Stress-Test**: Could a mismatch between canonical tags and edge redirects cause redirect loops?
- **Finding**: No. `buildMeta()` sets `canonicalUrl = "https://sitenova.dev/"` for root and `https://sitenova.dev/path` (without trailing slash) for all subpages. This is 100% congruent with the edge worker's 301 redirect logic.

### 3. Static Pricing Table SSR Hydration & CLS
- **Stress-Test**: Does the addition of a static pricing table to `WebsiteCostCalculator.tsx` cause layout shift (CLS) or React SSR hydration mismatches?
- **Finding**: No. The table is rendered as pure semantic HTML JSX without conditional client-side state hooks, ensuring identical DOM nodes between server render and client hydration.

### 4. Root Hreflang Conflict Resolution
- **Stress-Test**: Does removing hardcoded root hreflang tags in `root.tsx` break internationalization?
- **Finding**: No. SiteNova is a single-language (English - India `en-IN`) site. The static hreflang tag pointing to `https://sitenova.dev/` on every subpage was an active defect that sent invalid alternate language signals to Googlebot. Removing it consolidates indexing signals.
