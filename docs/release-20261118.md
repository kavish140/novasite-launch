## Included changes

- Studio visual redesign across public, private and admin pages; shorter homepage with dedicated portfolio, services, resources, reviews, FAQ and payment pages.
- Dedicated Business Websites service page and correct independent service/case-study routes. Unknown URLs now return HTTP 404.
- Compact mobile quote/audit layouts, confirmed-submission screens and editable budget suggestions based on current package prices or estimator totals. Visitor edits are preserved.
- Portfolio admin CRUD, visibility and ordering; AI SmartKit removed. The already-applied portfolio migration is included under its actual production version `20261118100613`.
- Payment admin tabs/cards, clear review buttons, existing receipts, payment tracking and project/recovery controls.
- Blog heading input regression fix, all 60 prior TypeScript errors resolved, and full-repository lint cleanup.
- `keep_vars: true` explicitly retains existing Cloudflare dashboard variables when deploying. Existing Supabase payment functions, credentials, price history and payment activation are retained.
