Separate the public edit from the client delivery vault

A public photography portfolio and a private delivery gallery have different security requirements. Public photographs can use a CDN and long-lived versioned asset URLs. Private wedding or commercial client files need authorisation appropriate to the agreement, a defined access lifetime and a removal process. Hiding a gallery from navigation is not access control, and a filename containing a client's name can expose more than the photographer intended.

Design the editorial selection first. A short sequence showing an assignment's range is more useful than loading every frame. Give each project a stable page, identify the photographer's actual role and obtain permission for public use. For commercial assignments, confirm whether publication is allowed before a campaign launches. Do not infer permission from the fact that a photograph is already visible on someone's social account.

Budget image bytes by viewport rather than by upload size

Generate several derivatives of an approved original and serve them using responsive markup. A phone gallery does not normally need a full-resolution print file. Compare WebP and AVIF output visually, including skin texture, gradients and darker scenes, and retain a fallback format. Compression is a delivery decision rather than an instruction to alter the appearance of the work.

Set dimensions for every thumbnail so the gallery has a stable layout. A masonry grid should preserve a sensible reading order and should not move the selected image away while the visitor is about to tap. Lazy-load photographs outside the opening viewport, while keeping the main visible image discoverable promptly. Google's CLS guidance explains the role of reserved space; a fast download alone does not prevent layout movement.

Validate the booking journey with two enquiries for one date

An availability enquiry is not a confirmed assignment. Collect event date, broad location, coverage type and preferred contact without making the visitor upload private invitations. If two couples enquire about the same date, the site should record both as requests and let the photographer decide availability. An automatic confirmation needs a real reservation process and appropriate contractual terms, not merely a green message after form submission.

Test duplicate clicks and a network interruption after the server accepts the request. The visitor should recover the same acknowledgement rather than create another lead on every retry. Measure useful outcomes such as reviewed enquiries and accepted assignments separately from gallery views or WhatsApp clicks. That distinction lets the photographer evaluate the website's operational contribution without inventing a conversion rate from browsing activity.
