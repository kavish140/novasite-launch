Model a room transformation without a shifting gallery

A before-and-after comparison is useful only when the visitor can understand what changed. Store each pair as one project component with a room label, image permissions and a caption describing the design intervention. Reserve a fixed aspect ratio before either photograph arrives, and make the control usable with a keyboard. If the images were taken from different positions, disclose that rather than implying a precise visual overlay.

Use responsive image widths and inspect the delivered files on a real phone. AVIF and WebP can reduce transfer size, but fabric texture, joinery detail and colour gradients still need visual review. Provide a fallback and appropriate alternative text. A hero image can load eagerly while project images below the fold load lazily; applying lazy loading indiscriminately can delay the very image a visitor came to see. Review the actual LCP candidate before choosing resource priorities.

Give renovation constraints their own place in the story

A useful interiors project describes the original brief, occupancy constraints, what was retained and what the designer actually delivered. A kitchen renovation in an occupied flat raises different coordination questions from a complete commercial fit-out. Explain those differences without inventing a client budget or a delivery promise. If photography excludes unfinished work or an unchanged room, keep the project description consistent with that selection.

Project metadata can include property type, broad area, scope and completion stage. It should not expose a household's exact address, personal possessions or security arrangements without approval. Check original image metadata before publication as well as what is visible in the photograph. Floor-plan downloads need separate review; a beautiful portfolio does not justify publishing a client's private residential layout.

Qualify the fit-out brief before asking for a site visit

For an illustrative enquiry, ask whether the visitor owns or occupies the space, whether it is residential or commercial, the approximate area and the work they want to discuss. Permit a broad budget range and an unknown option when the project is still exploratory. Record the distinction between design-only consultation and execution support. That gives the studio useful context without pretending an online calculator can provide a final renovation contract.

Route a successfully stored enquiry to a staff member with a clear acknowledgement to the visitor. Do not label a preferred site-visit time as confirmed until the studio accepts it. If drawings are requested later, deliver a controlled upload invitation rather than adding unrestricted public file uploads to the marketing form. These choices improve the quality of the handoff while keeping the initial journey short.
